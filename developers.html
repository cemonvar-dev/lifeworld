Fiblia API

Version 1 · Last updated 14 Nov 2026

Connect Fiblia to your own scripts and tools: create tasks, mark them done, and read what is due today.

Authentication

Create a key in the app under Settings → Account → API keys. Send it with every request:

Authorization: Bearer fib_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

A key acts as you, on your data only. Keys can be read only or read & write, and you can revoke one at any time. Treat a key like a password and never put it in a web page or a public repository.

Base URL: https://fiblia.com/api/v1. Requests and responses are JSON. Each key can make up to 5,000 requests per day.

Dates and time zones

Dates are YYYY-MM-DD. "Today" is computed in the time zone you pass as ?tz=Europe/Istanbul or an X-Timezone header; it defaults to UTC.

Tasks

GET/tasks List tasks. Filters: status (active default = not completed or cancelled, all, in progress, planned, completed, cancelled), tag (id, name or path; includes sub-tags), due=today, pinned=true, q (name contains).

GET/tasks/{id} One task.

POST/tasks Create a task.

FieldTypeNotes
namestringRequired.
frequencystringonce (default), daily, weekly, monthly
datedateDue date for one-time tasks. Omit for "someday".
weekdaysint[]Weekly tasks: 0 = Sunday … 6 = Saturday.
day_of_monthintMonthly tasks: 1–31.
tagsstring[]Tag ids, names, or paths like family › defne (also family/defne).
create_tagsboolCreate tags that don't exist yet (nested paths too).
notes, pinnedstring, boolOptional.
curl -X POST https://fiblia.com/api/v1/tasks \
  -H "Authorization: Bearer $FIBLIA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"Send the QA tracker","date":"2026-11-20","tags":["work"]}'

PATCH/tasks/{id} Update any of the fields above, plus status (in progress, planned, completed, cancelled). To retire a task, set status to completed or cancelled.

Done and Skip

POST/tasks/{id}/logs Body: {"status":"done"} or "skipped", optional date (default today) and note. Logging the same day again replaces that day's status.

curl -X POST "https://fiblia.com/api/v1/tasks/TASK_ID/logs?tz=Europe/Istanbul" \
  -H "Authorization: Bearer $FIBLIA_API_KEY" \
  -H "Content-Type: application/json" -d '{"status":"done"}'

GET/tasks/{id}/logs History, with from / to (default: last 30 days).

DELETE/tasks/{id}/logs?date=YYYY-MM-DD Clear that day's Done/Skip.

Tags, summary, key info

GET/tags All tags with id, name, path, parent_id, color.

GET/summary What is due on a day (date, default today) with counts of done, skipped and open.

GET/me The key's name and scopes.

Errors

Errors use HTTP status codes and a body like {"error":{"code":"invalid_request","message":"…"}}. Codes: unauthorized (401), forbidden (403, key lacks write access), not_found (404), invalid_request / unknown_tags (400), rate_limited (429).
